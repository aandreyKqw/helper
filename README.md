# Что делает mvp за поток 1: 

Реализация cli 

### Ежедневно собирает инфу от пользователя 
* Количество ккал за день (бжу) ( на старт просто ввод)
* Вес 
* Была ли тренировка , если да то сколько по времени бег, ходьба , время самой тренировки  (пока что) 
* Время сна (просто часы)
* Хотелось ли сорваться 

### Как работает и вывод на экран:

#### Write Data
1) Пользователь запускает в CMD cli-приложение с тегами --write
2) mvp опрашивает пользователя и сохраняет данные в БД 
#### Show Data
1) Пользователь запускает в CMD cli-приложение с тэгами --static 
тэг --7days - выводит всю инфу за 7 дней 
тэг --month - выводит всю инфу за месяц 
2) Вывод инфы на экран 
#### Delete Data (only for me)
1) Пользователь запускает в CMD cli-приложение с тэгами --delete 
2) Сервис спрашивает по какому Primary key удалить
